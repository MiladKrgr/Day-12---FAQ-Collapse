## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->
این پروژه یک کامپوننت تعاملی از بخش سوالات متداول (FAQ / Accordion) است که با هدف تمرین پیمایش در ساختار سند (DOM Traversal) و مدیریت کلاس‌های وضعیت در جاوااسکریپت پیاده‌سازی شده است. در این کامپوننت، کاربران می‌توانند با کلیک بر روی دکمه چرخشی تعبیه‌شده در هر کارت، پاسخ سوال را باز یا بسته کنند؛ این تغییر وضعیت همراه با تغییر آیکون، تغییر پس‌زمینه و انیمیشن‌های نرم CSS صورت می‌پذیرد.

---
---
---


## ویژگی ها  
<!-- Features : استاندارد -->

- باز و بسته شدن تعاملی کارت‌ها با استفاده از متد classList.toggle() در جاوااسکریپت
- پیمایش دقیق در درخت DOM با بهره‌گیری از خاصیت parentNode
- استفاده از آیکون‌های Font Awesome (آیکون‌های Chevron و Times/Close) متناسب با وضعیت کارت
- پیاده‌سازی افکت‌های بصری نرم، سایه‌ها و آیکون‌های دکوراتیو پس‌زمینه با شبه‌عناصر (::before و ::after)
- طراحی کاملاً واکنش‌گرا (Responsive) و متمرکز با چیدمان Flexbox

## Project Description 📌
<!-- Standard : Project Description  -->
This project is an interactive FAQ (Frequently Asked Questions) accordion component built to practice DOM traversal and dynamic class toggling in Vanilla JavaScript. Users can expand or collapse each question card by clicking the toggle button, triggering smooth CSS transitions, background color changes, and swapping between chevron and close icons.

---
---
---

## Features 🌏
<!-- Standard : features  -->
- Interactive card collapse/expand functionality using JavaScript’s classList.toggle()
- Efficient DOM tree traversal using the parentNode property
- Dynamic icon swapping with Font Awesome (Chevron Down & Times/Close)
- Smooth visual effects, card shadows, and subtle decorative background icons via CSS pseudo-elements (::before & ::after)
- Clean, centered, and fully responsive layout powered by CSS Flexbox
